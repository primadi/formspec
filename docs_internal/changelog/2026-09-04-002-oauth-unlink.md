# 2026-09-04-002 — OAuth unlink (remove external sign-in method)

## Apa yang diubah

Menambahkan unlink untuk melengkapi explicit linking (todo 5.2.21).

- **Backend** — `internal/auth/user.go`: `EntityUserStore.UnlinkOAuthIdentity`
  (clear `oauth_provider` + `oauth_sub`). `internal/auth/service.go`:
  `Service.UnlinkOAuthIdentity` — provider harus yang sedang ter-link
  (`ErrNotLinked`), dan akun harus tetap punya metode login (`ErrUnlinkRequiresPassword`
  untuk akun pure-OAuth tanpa password); notifikasi email saat unlink.
  `internal/api/oauth_handler.go`: `HandleOAuthUnlink` (authenticated);
  `internal/api/router.go`: route `POST /_ui/auth/oauth/{provider}/unlink`.
- **Frontend** — `LinkedAccountsDialog.tsx`: provider ter-link kini punya
  tombol "Unlink" (two-step inline confirm), POST ke endpoint unlink, lalu
  refresh identity via `fetchMe`; error `UNLINK_REQUIRES_PASSWORD` tampil
  sebagai toast.

## Kenapa

User yang sudah link provider perlu bisa melepasnya. Guard `ErrUnlinkRequiresPassword`
mencegah lockout: akun yang hanya punya OAuth (tanpa password) tidak boleh
kehilangan satu-satunya metode login — harus set password dulu.
