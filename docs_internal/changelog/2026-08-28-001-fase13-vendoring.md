# 2026-08-28-001 — Fase 13.1: Local vendoring & activation

## Apa yang diubah

Implementasi §6.1–§6.3 `08-project-layout.md` (todo 13.1.1–13.1.6) — vendoring
module offline-first:

- **`internal/vendor/`** (package baru):
  - `lock.go` — `formspec.lock` (source, name, alias, version, checksum
    sha256-tree, signature, trust_tier, installed_at) + `TreeChecksum`
    deterministik + `NormalizeSource`.
  - `marker.go` — blok marker terstruktur `# >>> formspec:vendor <source>
@<version>` di list `modules:` App manifest; upsert idempotent yang
    mempertahankan status aktif (D-g) kecuali `--use` eksplisit; indentasi
    marker mengikuti indentasi list agar manifest tetap YAML valid.
  - `alias.go` — alias Opsi B (D-e): dihitung saat install terhadap semua
    module ter-install + lokal; derivasi `{org}-{name}` (prefix match untuk
    repo `{name}-module`).
  - `install.go` — flow install (fetch git/folder/tarball → stage → validate
    via loader engine → copy → normalisasi `metadata.name` ke nama efektif →
    checksum → lock → marker), `Uninstall`, `Verify`, `ActiveModules`.
- **Boot-time enforcement (13.1.4)** — hanya module vendor AKTIF yang
  di-register: root `vendors/{name}` ditambahkan ke entity registry DAN loader
  resolusi App/Module (sebelumnya loader terpisah tanpa vendor roots —
  `modules:` referensi ke vendor gagal resolve). Module nonaktif diam di disk.
- **CLI (13.1.2/13.1.5/13.1.6)** — `formspec module install|list|uninstall`,
  `formspec verify`; flag reorder agar `--use` setelah posisional tetap
  ter-parse.
- **Harden `internal/app/resolve.go`** — `module.yaml`/App tanpa `spec:`
  tidak lagi panic (error jelas).
- **Loader seam** — `Loader.SetAliases` untuk rewrite `metadata.module`
  (normalisasi nama efektif dilakukan di install-time; seam tersedia untuk
  kebutuhan berikutnya).

## E2E terverifikasi (smoke test)

Install dari folder → marker inactive → `verify` OK → tamper `vendors/` →
`verify` FAIL → `--use` aktifkan → boot `formspec dev` → entity vendor
`billing/invoices` reachable via API → comment marker → boot → 404 (tidak
ter-register).
