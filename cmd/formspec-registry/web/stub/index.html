SPA tidak ter-embed di binary registry ini

Binary formspec-registry ini dibangun tanpa embedded SPA (build default, mis. via go install — yang tidak bisa menjalankan npm). UI tersedia lewat:

  • formspec spa install — download & cache SPA dari GitHub Releases versi binary ini
  • make build-registry — build SPA lalu embed via -tags formspec_spa
  • --web-dir <folder> — serve SPA dari folder
