# 2026-08-28-003 — Fase 13.3: Module Registry (dogfooding POC) + sign/publish/install

## Apa yang diubah

Implementasi loop registry end-to-end (todo 13.3.1–13.3.8, kecuali 13.3.5/13.3.9):

- **13.3.1 — `verticals/registry/spec/`** (scaffold): App `registry` + Module
  `registry` + entities `Vendor` (ed25519 public key), `Module` (katalog,
  trust_tier, ai_index), `ModuleVersion` (semver, checksum, signature,
  tarball file field, state machine draft→published→deprecated). Validate
  hijau engine + schema. Fix: field `version` reserved → `semver`;
  `transaction_date` wajib nama persis; `natural_key` adalah atribut field.
- **13.3.4 — spec.expose**: public read (list/find) + create/submit untuk
  publish; `submit` ditambahkan ke expose vendor/module (relation target
  wajib past-draft).
- **13.3.6 — `formspec sign`**: `keygen` (ed25519 keypair, private 0600),
  `sign <module-dir>` (tree checksum → signature base64), `verify` (tamper
  detection terverifikasi E2E).
- **13.3.7 — `formspec module publish`**: tar module → checksum → sign →
  find-or-create vendor/module (submit otomatis) → create version → upload
  tarball (multipart, MIME application/gzip). **Versi immutable**: re-publish
  semver sama dengan content berbeda ditolak.
- **13.3.8 — `formspec module install --from <registry> <module>[@ver]`**:
  lookup version → download tarball → **verifikasi signature terhadap
  public key vendor terdaftar SEBELUM percaya tarball** (checksum mismatch →
  REFUSED) → flow install 13.1. Lock mencatat registry ref + signature.
- **`internal/vendor/registry.go`** — RegistryClient (REST surface
  workspace-scoped `/{ws}/api/v1/...`; CRUD plural, file upload/download
  singular; filter client-side — list endpoint tidak mendukung filter
  arbitrer).
- **`internal/vendor/sign.go`** — ed25519 helpers (keygen/sign/verify/
  derive-public-key/save-load).

## E2E terverifikasi (smoke test penuh)

keygen → sign → verify → tamper → verify FAIL → boot registry app (`formspec
dev --spec verticals/registry/spec`) → publish billing@1.0.0 → install --from
di project konsumen (signature verified) → boot konsumen → module vendor
ter-register. Re-publish semver sama content berbeda → ditolak (immutability).
